<h1 align="center">Cream Soda</h1>

<p align="center">Фронтенд для ролевых чатов с ИИ в духе SillyTavern: сервер, интерфейс и лаунчеры для ПК и Android.</p>

Cream Soda читает карточки, лорбуки, пресеты, регексы и чаты SillyTavern в их форматах и умеет сохранять их обратно. Работает локально: данные лежат на вашем компьютере или телефоне, наружу уходят только запросы к выбранной модели.

Интерфейс на английском (по умолчанию) и русском: «Settings → General → Interface language». Лаунчеры для ПК и Android говорят на том же языке, что и приложение. Профили, созданные до появления выбора языка, остаются на русском.

## Быстрый старт

Нужен Node.js 18.17 или новее (рекомендуется 20+).

```bash
npm install        # ставит зависимости сервера и интерфейса
npm run build      # собирает интерфейс в web/dist
npm start          # http://127.0.0.1:8000
```

После запуска откройте **Настройки → Подключения** и добавьте модель: OpenAI-совместимый API, Anthropic, Google AI, OpenRouter, Text Completion (KoboldCpp, llama.cpp, oobabooga, TabbyAPI…) или Ollama. При первом запуске уже есть демо-персонаж Ханами Рин с лорбуком «Ночной Сибуя».

Параметры сервера:

```
npm start -- --port 8000 --lan --data ./data --profile default --open
```

| Флаг | Что делает |
| --- | --- |
| `--port <n>` | Порт (по умолчанию 8000; если занят, берётся следующий свободный) |
| `--strict-port` | Не подбирать порт, а выйти с ошибкой |
| `--lan` | Пускать телефоны из той же Wi-Fi сети (по токену из QR-кода) |
| `--data <путь>` | Папка с данными (по умолчанию `./data` или `CREAM_SODA_DATA`) |
| `--profile <имя>` | Профиль данных: отдельный набор персонажей, чатов и настроек |
| `--open` | Открыть интерфейс в браузере |

### Попробовать без модели

```bash
npm run mock-llm   # OpenAI-совместимая заглушка на http://127.0.0.1:5055/v1
```

Добавьте подключение «OpenAI-совместимый» с адресом `http://127.0.0.1:5055/v1` и любой моделью. Заглушка стримит готовые реплики, отвечает вариантами для Impersonate+, пишет конспекты для Memory Book и создаёт карточки в генераторе.

## Возможности

**Чат**
- Свайпы, продолжение реплики, перегенерация, правка и удаление, скрытие сообщений из контекста, ветки от любого сообщения, поиск по чату, список чатов персонажа.
- Групповые чаты: порядок естественный, по списку, по очереди (pooled) или вручную. Участников можно заглушить, есть авторежим.
- **Impersonate+**: несколько вариантов вашей реплики сразу, с направлением («мягкий флирт, без спешки») и режимами («Только действие», «Голос персоны», «Продолжить мою реплику»). Варианты пишутся от третьего лица. Панель над полем ввода можно скрыть кнопкой с перечёркнутым глазом; вернуть её можно из меню «+» у поля ввода или в «Settings → General». Сама функция при этом остаётся в меню «+».
- Персоны пользователя, Author's Note, переменные чата и глобальные переменные.
- Быстрые ответы (Quick Replies) и слэш-команды в духе STscript с пайпами `|`: `/send`, `/sendas`, `/sys`, `/gen`, `/genraw`, `/continue`, `/regen`, `/impersonate`, `/roll 2d6`, `/setvar`, `/getvar`, `/addvar`, `/persona`, `/preset`, `/profile`, `/newchat`, `/bg`, `/memory`, `/image`, `/translate`, `/speak`, `/theme`, `/input`, `/echo`, `/help` и другие.
- Перевод сообщений через модель, озвучка (Web Speech), броски кубиков.

**Промпт**
- Все промпты, которые отправляются модели, написаны на английском при любом языке интерфейса. Модель просят отвечать на языке чата. Это касается стандартных пресетов, Impersonate+, Memory Book, перевода, картинок и генератора.
- Свои промпты Cream Soda (Impersonate+, Memory Book, перевод, кадр сцены и портрет, генератор, вложенные файлы) можно править в «Settings → Prompts». Изменённый промпт помечается, кнопка «Reset to default» возвращает стандартный. Основной промпт, пост-инструкция и остальные блоки правятся в пресетах, промпты персонажа — в карточке. Русские промпты из старых версий при обновлении заменяются английскими. Промпты, которые вы меняли сами, сохраняются.
- Менеджер промпта как в SillyTavern: блоки с маркерами, порядок перетаскиванием, вставка на глубину, роли, префилл, склейка системных сообщений, имена в сообщениях.
- Пресеты сэмплеров (температура, top-p/k, min-p, rep. penalty, DRY, XTC, мысли/reasoning и др.).
- Text Completion с instruct-шаблонами: ChatML, Llama 3, Mistral V7, Gemma, Alpaca, Metharme, GLM-4 и свои.
- Макросы SillyTavern (`{{char}}`, `{{user}}`, `{{random}}`, `{{pick}}`, `{{roll}}`, `{{getvar}}`, `{{time}}`…), подсчёт токенов (o200k/cl100k) и предпросмотр итогового промпта.

**World Info / лорбуки**
- Ключи и вторичные ключи с логикой AND ANY / AND ALL / NOT ANY / NOT ALL, регулярные выражения, рекурсия, группы, sticky / cooldown / delay, вероятность, позиции вставки и бюджет.
- Импорт и экспорт лорбуков SillyTavern, встроенные лорбуки карточек.

**Memory Book**
- Главы: часть чата сжимается в запись, а модель помнит главное. Факты можно закрепить, есть бюджет токенов памяти.

**Персонажи**
- Карточки V1, V2 и V3: PNG (`chara` / `ccv3`) и JSON. Импорт по ссылке, в том числе с Chub.
- Редактор всех полей, альтернативные приветствия, теги, избранное. Генератор персонажей по описанию.

**Остальное**
- Регексы SillyTavern: на вывод, на ввод, только для отображения или только для промпта, с проверкой на тексте.
- JavaScript в плашках сообщений (статус-панели, трекеры, блоки ```html с `<script>`) включается в «Settings → General» или «Settings → Chat». По умолчанию выключен. Такие плашки работают в изолированном iframe с собственным origin (`sandbox="allow-scripts"` без `allow-same-origin`). Им недоступны интерфейс, ключи, `localStorage` приложения и изменяющие запросы к серверу Cream Soda. Высота рамки подстраивается под содержимое. Пока ответ стримится, скрипты не запускаются.
- Генерация картинок: AUTOMATIC1111, ComfyUI (свой workflow), OpenAI Images или свой JSON-шаблон. «Кадр сцены» по последним сообщениям.
- Темы: Cream Soda, Midnight Soda, Strawberry, Pudding, свои цвета и CSS. Безопасный режим без своего CSS: `?safe` в адресе или Shift при запуске из лаунчера.
- Расширения из git-репозиториев (`manifest.json` в формате SillyTavern). API `window.CreamSoda` и частичная совместимость с `SillyTavern.getContext()`.
- Бэкапы: полный zip профиля, ежедневный автобэкап (по умолчанию хранятся последние 7), восстановление с копией текущего состояния.
- Журнал запросов к моделям (ключи вырезаны). Прокси HTTP(S) и SOCKS4/5 для каждого подключения.
- Мобильная вёрстка: на телефоне интерфейс перестраивается под нижнюю навигацию.

## Лаунчеры

### ПК (Windows, macOS, Linux)

Электрон-лаунчер запускает сервер внутри себя и открывает интерфейс в окне приложения или в браузере. В нём же: QR-код для телефона, профили, бэкап и логи.

```bash
npm run launcher                              # запуск из исходников
npm --prefix launcher/desktop run dist:win    # установщик и portable .exe
npm --prefix launcher/desktop run dist:mac    # .dmg
npm --prefix launcher/desktop run dist:linux  # AppImage и tar.gz
```

Перед сборкой выполните `npm install` в `launcher/desktop` и `npm run build` в корне. Готовые файлы появляются в `launcher/desktop/dist`. Данные установленного приложения хранятся в папке пользователя (`%APPDATA%/Cream Soda/data`, `~/Library/Application Support/Cream Soda/data`, `~/.config/Cream Soda/data`). Portable-версия держит данные рядом с .exe, в папке «Cream Soda data».

Сборки не подписаны сертификатами Microsoft и Apple, поэтому при первом запуске система предупредит:

- **Windows**: «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS**: распакуйте zip, перенесите «Cream Soda» в «Программы», затем правый клик → «Открыть». На macOS 15 и новее: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Если система пишет, что приложение повреждено, выполните `xattr -cr "/Applications/Cream Soda.app"`. Для Mac с Apple Silicon берите архив `mac-arm64`, для Mac на Intel — `mac-x64`.
- **Linux**: `chmod +x Cream-Soda-*.AppImage`, затем запустите файл.

### Android

Сервер работает прямо на телефоне. Сборка APK, устройство и ограничения описаны в [launcher/android/README.md](launcher/android/README.md).

### Телефон + ПК

Включите в лаунчере на ПК «Открыть с телефона» (или запустите сервер с `--lan`) и отсканируйте QR-код камерой телефона либо кнопкой «Подключиться к ПК» в Android-приложении. В QR-коде есть токен доступа: без него устройства из сети получат отказ.

## Разработка

```bash
npm run dev        # сервер на :8000 и Vite с горячей перезагрузкой на :5173
npm test           # тесты сервера (node:test)
npm run check      # проверка типов интерфейса + тесты
```

```
server/            Express-сервер: хранилище, прокси к LLM, картинки, расширения, бэкапы
  src/llm/         адаптеры OpenAI / Anthropic / Google / Text Completion / Ollama
  test/            тесты сервера
web/               интерфейс: React 18 + TypeScript + Vite + zustand
  src/lib/         движок: промпт, макросы, World Info, регексы, instruct, Memory Book, STscript
  src/lib/prompts.ts  промпты Cream Soda (английские) и их правка
  src/lib/i18n.ts  t('English text') → перевод из src/i18n/ru.ts
  src/pages/       экраны: чат, библиотека, пресеты, генератор, память, картинки, регексы, модули, настройки
launcher/desktop/  Electron-лаунчер и сборка установщиков
launcher/android/  Capacitor-приложение с Node.js на телефоне
assets/brand/      логотип и иконки
scripts/           dev-режим, заглушка LLM, генерация иконок
```

Строки интерфейса пишутся по-английски через `t()` / `tn()` из `web/src/lib/i18n.ts`, русский перевод лежит в `web/src/i18n/ru.ts` под английским ключом. Для множественного числа ключ имеет вид `'message|messages'`, а перевод — `'сообщение|сообщения|сообщений'`. Ошибки сервера приходят по-английски, и интерфейс переводит знакомые ему сообщения.

Данные профиля лежат в `data/profiles/<профиль>/` в виде обычных JSON-файлов: персонажи, лорбуки, пресеты, чаты (`chats/<владелец>/<id>.json`), загруженные файлы (`files/`).

## Безопасность

- По умолчанию сервер слушает только `127.0.0.1`. Доступ из сети включается явно и требует токен из QR-кода.
- Проверки `Host` и `Origin` защищают от DNS rebinding и запросов с чужих сайтов.
- API-ключи шифруются AES-256-GCM. Ключ шифрования лежит в `data/.cs-key`: ключи не видны в файлах профиля и бэкапах, но тот, у кого есть вся папка `data`, сможет их расшифровать. В бэкап ключи попадают, только если явно это выбрать.
- В интерфейс ключи возвращаются только в маскированном виде. Показать ключ целиком можно лишь на этом же устройстве.
- Загруженные файлы проверяются по сигнатуре: SVG или HTML под видом картинки не будут отданы как изображение.
- Расширения выполняют свой код в интерфейсе с полным доступом к нему. Ставьте только те, которым доверяете.
- Скрипты из сообщений (если их включить) работают в песочнице без доступа к интерфейсу. Из интернета они при этом загружать могут. Включайте их только для карточек, которым доверяете.
